# KnotCipher

A decorative art font inspired by knot patterns.

> ⚠️ This font is purely artistic and **not designed for reading**.

## Features

- Unique knot-based letterforms
- Available in TTF and OTF formats

## Installation

1. Download the font file from [Releases](../../releases)
2. Double-click the file and click "Install"
